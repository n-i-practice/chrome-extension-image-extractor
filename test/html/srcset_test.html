srcset テストページ

Image Extractor の srcset 抽出ロジックを検証するためのページです。

① src のみ

期待値：400x400.png

② srcset（w のみ）

期待値：500x500.png（最大 w）

③ srcset（x のみ）

期待値：500x500.png（最大倍率）

④ srcset（w と x の混在）

期待値：500x500.png（500w と 4x=400 の比較 → 500w が最大）

⑤ descriptor なし（仕様どおり先頭が採用される）

期待値：100x100.png（descriptor なし → 先頭が採用）

⑥ src なし / srcset のみ

期待値：500x500.png（最大 w）

⑦ src も srcset もなし（抽出されないことを確認）

期待値：抽出なし
