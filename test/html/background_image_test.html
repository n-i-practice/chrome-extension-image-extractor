background-image テストページ

Image Extractor の background-image 抽出ロジックを検証するためのページです。

① CSS クラスの background-image

期待値：200x200.png

② インライン style の background-image

期待値：100x100.png

③ ::before の background-image

期待値：300x300.png

④ gradient + url の混在

期待値：400x400.png（gradient は無視）

⑤ background-image なし（抽出されないことを確認）

期待値：抽出なし

⑥ 同一 URL が img と background-image に存在（重複除外）

期待値：500x500.png が 1 件のみ（正規化後の重複パスは除外）
