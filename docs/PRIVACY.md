# Image Extractor プライバシーポリシー案

確認用の日本語案です。公開前に内容と問い合わせ先を確定します。

作成日：2026年10月16日

Image Extractor（以下「本拡張」）は、Webページの画像を抽出し、一覧・拡大表示するChrome拡張です。

## 取得する情報と利用目的

本拡張は、利用者が拡張アイコンを押したページのURL・画像URL、画像サイズなどを取得し、画像の抽出・表示・フィルターに使用します。一覧の管理に必要な一時的な識別情報や件数、表示言語も取り扱います。表示言語はブラウザーの設定と利用者の選択から決定します。

操作していないページの画像を自動収集したり、閲覧履歴全体を収集したりする機能はありません。

## 保存と削除

画像URLと一覧管理用の情報はブラウザー内に一時保存し、同じ一覧を開いている最後のViewerタブを閉じたとき、またはブラウザー終了時に削除します。画像サイズや表示中の状態も一時的に使用します。表示言語は次回以降のために保存し、Viewerで変更できます。本拡張をアンインストールすると、拡張の保存データは削除されます。

画像表示に伴うChromeのキャッシュや閲覧履歴はブラウザー自身が管理し、Viewerを閉じても削除されません。本拡張が画像ファイルを独自の保存先へ永続保存することはありません。

## 画像表示時の通信

外部から配信される画像を表示する際は、その配信元へ通信します。元ページとは異なるドメインへアクセスする場合もあり、配信元には画像URLやIPアドレスなどの通信情報が送信されます。

Cookieなどの送信有無はブラウザーの設定や通信先の条件によります。本拡張がCookieを読み取って収集する機能はありません。

## 開発者への送信と利用範囲

本拡張が取得した情報を開発者のサーバーへ送信する機能や、利用状況のアクセス解析・広告の仕組みはありません。情報は画像の抽出・閲覧と、それに必要な設定・一覧管理に使用し、販売、パーソナライズ広告、信用評価・融資審査には使用しません。

利用者データの取扱いは、Limited Useの要件を含む [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/policies#protecting-user-privacy) に従います。

## Ko-fiによる任意の支援

支援ボタンを押すと [Ko-fi](https://ko-fi.com/F8U228LZP5) のページを別タブで開きます。ボタンの表示だけではKo-fiへ通信せず、抽出した画像URLや一覧管理用の情報を支援ページへ送信しません。支援の有無による機能制限はありません。

移動後はKo-fiと決済サービスの規約・プライバシーポリシーが適用され、支援に伴い開発者へ提供される情報も各サービスの方針に従います。本拡張内でカード情報や決済の認証情報を取得することはありません。

データの取扱いが変わる場合は、本ポリシーを更新し、公開ページに変更内容と更新日を反映します。
