# Image Extractor ストアのプライバシー申告記録

2026-10-24にChrome Web Storeの入力項目と実装・公開ポリシーを照合し、下書き保存を確認しました。同日、ユーザーがバージョン1.0の審査申請を完了したと報告しています。現在は審査結果待ちです。以下は申告内容と実装の対応を残すための記録です。

## 単一の目的

利用者が開いているWebページから画像URLを抽出し、別タブで一覧表示して、サイズや拡張子のフィルターと拡大・原寸表示で画像を確認できるようにします。

## 権限の説明

| 権限 | 入力する説明 |
| --- | --- |
| `activeTab` | 利用者が拡張アイコンを押した際に、対象タブの画像要素とCSS背景画像から画像URLを抽出するため、一時的にページへアクセスします。 |
| `scripting` | 利用者が選んだページに画像抽出用のcontent scriptを注入し、画像URLを取得するために使用します。 |
| `storage` | 抽出した画像URLとViewerの参照情報をブラウザー内に一時保存し、Viewerの複製・終了時に一覧を保持・削除するために使用します。また、利用者が選んだ表示言語を保存します。 |

`tabs` 権限と全サイトへの `host_permissions` は要求していません。

## リモートコード

申告内容：リモートコードは使用していません。

実行するJavaScriptは拡張に同梱しています。Ko-fiの支援ボタンも画像を同梱し、外部のウィジェットスクリプトは実行していません。画像の配信元へのリクエストと、利用者が押したKo-fiへのリンクは、リモートコードの読み込みとは区別します。

## データの種類と用途

ブラウザー内だけで処理・保存していても、データの取扱いを説明します。「開発者のサーバーへ送信しない」ことを理由に、データを扱わないと申告しません。

| 申告項目 | この拡張での扱いと申告内容 |
| --- | --- |
| ウェブサイトのコンテンツ | 対象。ページ内の画像要素・CSS背景画像から画像URLを取得し、画像と画像サイズを表示します。用途は画像一覧・フィルター・拡大表示です。 |
| ウェブ閲覧履歴 | 対象として申告。操作したページのURLを相対画像URLの解決に使用し、解決後の画像リソースのURLを保存・表示します。元ページのURLを閲覧履歴として別途保存する機能はありません。ブラウザーの履歴一覧を取得する機能や、全ページの巡回・追跡機能はありません。 |
| その他の処理・保存情報 | 表示言語、一覧ごとのランダムなセッションID、タブID・参照情報、画像件数・通知情報。言語設定と一覧管理だけに使用します。ストアの項目名・定義と照合し、追加のデータ種類にはチェックしていません。 |

氏名・連絡先、カード番号などの決済情報、ログイン情報、健康情報、通信メッセージなどを独立した項目として読み取って記録する機能はありません。ただし、画像の内容やURLには個人に関する情報が含まれる場合があるため、「画像には個人情報が含まれない」とは説明しません。

画像配信元への通信情報と、Ko-fiの支援ページでの情報の取扱いは、プライバシーポリシーに記載します。本拡張による処理と、外部サービス内での決済を区別します。

## データ利用に関する確認事項

実装・運用方針に照らして、次の内容を確認します。

- 利用者データを第三者へ販売しない。
- データを画像の抽出・閲覧という単一の目的と、それに必要な設定・セッション管理のために使用する。
- データをパーソナライズ広告や信用評価・融資審査に使用しない。
- 開発者のサーバーへの画像URL・利用状況の送信や、外部アクセス解析を組み込んでいない。
- ストアの申告、公開するプライバシーポリシー、実際の実装を一致させる。

## 実装との対応

- `src/content/content.ts`・`src/content/extractors/`：操作したページ内の画像URL抽出と、相対URLの解決。
- `src/background/background.ts`・`src/shared/session-keys.ts`：画像URL・通知・タブ参照の保存と削除、一時受け渡し。
- `src/viewer/viewer.ts`：画像配信元からの画像表示、サイズ・拡張子の表示、フィルター・拡大表示。
- `src/i18n/index.ts`：ブラウザー言語の参照と、選択した表示言語の保存。
- `src/viewer/viewer.html`：Ko-fiのリンク先、同梱した画像ボタン、`noopener noreferrer` の設定。
- `manifest.json`：要求する権限。
