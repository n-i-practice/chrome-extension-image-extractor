# Image Extractor Privacy Policy

Created: October 16, 2026

Updated: October 21, 2026

[日本語](PRIVACY.md)

Image Extractor (the “Extension”) is a Chrome extension that extracts images from web pages and displays them in a list and an enlarged view.

## Information handled and its purposes

The Extension obtains image URLs from the page on which you click the extension icon and uses them to extract, display, and filter images. It uses the source page URL to resolve relative image URLs into absolute URLs. The image list stores the resulting image URLs. The Extension has no feature that separately saves source page URLs as browsing history.

The Extension also handles image dimensions, temporary identifiers needed to manage image lists (a random ID for each list, viewer tab IDs, and the associations between tabs and lists), image counts, and the display language. These identifiers are used to manage list retention and deletion. The display language is determined by your browser settings and your selection.

The Extension does not automatically collect images from pages you have not activated it on, or collect your entire browsing history.

## Storage and deletion

Image URLs and list management information are stored temporarily in the browser's session storage for the Extension. The Extension performs deletion when you close the last viewer tab displaying the same list. If temporary data remains because deletion fails, processing is interrupted, or a similar issue occurs, it is cleared when the browser exits and restarts.

Image dimensions and display state are also used temporarily. Your display language is saved separately for future use and can be changed in the viewer. Uninstalling the Extension removes its stored data.

Chrome manages any cache and browsing history it saves separately from the Extension's temporary data. The Extension does not perform any operation to delete them when you close the viewer. What Chrome records when loading images or using the viewer depends on Chrome's behavior and settings. The Extension does not persistently save image files to its own storage location.

## Network requests when displaying images

Displaying externally hosted images sends requests to their hosts. These hosts may be on domains different from the source page. Image URLs, IP addresses, and other network request information are sent to the image hosts.

Because the browser retrieves images, it may automatically send cookies for the destination according to the browser's behavior and settings and the destination's conditions. The Extension has no feature that reads and collects cookies.

## Transmission to the developer and use of information

The Extension has no feature that sends the information it obtains to the developer's server, and includes no usage analytics or advertising system. Information is used to extract and view images and to manage the necessary settings and image lists. It is not sold or used for personalized advertising, credit assessment, or lending decisions.

The handling of user data complies with the [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/policies#protecting-user-privacy), including its Limited Use requirements.

## Optional support through Ko-fi

Clicking the support button opens the [Ko-fi page](https://ko-fi.com/F8U228LZP5) in a separate tab. Displaying the button alone does not contact Ko-fi, and the Extension does not send extracted image URLs or list management information to the support page. Features are available regardless of whether you contribute.

After you open the support page, the terms and privacy policies of Ko-fi and the payment service apply. Information provided to the developer in connection with a contribution is also governed by those services' policies. The Extension does not obtain card details or payment authentication information within the Extension.

## Contact

For questions about data handling, contact the project through [GitHub Issues](https://github.com/n-i-practice/chrome-extension-image-extractor/issues).

A GitHub account is required to post. Issues are public, so do not include personal information, credentials, or private page URLs or images.

## Policy changes

If data handling changes, this policy will be updated. The changes and the updated date will be reflected on the published policy page.
