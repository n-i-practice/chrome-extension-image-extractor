### 補足

- v1 の対象は「ユーザーに見える文言」のみ
- 内部ロジックや抽出処理の変数名、ログ文言は対象外
- 辞書キーは辞書ファイル作成後に決める（辞書自体をドキュメントとする）
- UI の多言語対応は辞書ベースで統一管理する
- locale 決定順: 保存設定 → ブラウザ言語 → `en`
- ~~manifest / `_locales` は別ステップで対応する~~（完了。`default_locale: en`）
- `_locales` の `appName` は en/ja とも "Image Extractor"（製品名は共通）
- ツールバーの `actionTitle`（ホバー時ツールチップ）は `_locales` で定義済み。ピン留め状態などでは見えにくい場合あり
