  - aria-label

- 状態表示

### 📝 補足

- v1 の対象は「ユーザーに見える文言」のみ
- 内部ロジックや抽出処理の変数名、ログ文言は対象外
- 辞書キーは辞書ファイル作成後に決める（辞書自体をドキュメントとする）
- UI の多言語対応は辞書ベースで統一管理する
