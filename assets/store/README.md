# Image Extractor 掲載素材

## 作成済み

- `promo/promo-v2-440x280.png`：提出用の紹介画像。440×280px、RGB PNG。Webサイト→画像一覧→拡大表示の構成。
- `promo/promo-v2-source.png`：v2の生成元。
- `demo/alpine-lake.jpg`：拡大・原寸確認用のAI生成風景。1536×1024px。
- `demo/*.svg`：独自図形7点。透明部分と小サイズの確認用を含む。
- `demo/index.html`：8枚の画像を並べた撮影用ギャラリー。

紹介画像と風景画像は組み込みのImageGenで生成。紹介画像は既存の写真フレームアイコンを参照。外部の写真サイトの素材は使用していない。プロンプトは `PROMPTS.md` に記録。図形とページは `node assets/store/demo/create-demo.cjs` で再生成できる。撮影用素材は配布ビルドに含めない。

## Chromeでの撮影手順

1. プロジェクトのルートで `npm run build` を実行し、Chromeで `dist/` の拡張を読み込むか再読み込みする。
2. `node assets/store/demo/serve.cjs` を実行する。
3. 同じPCのChromeで `http://127.0.0.1:4175/` を開く。8枚が表示されたら拡張アイコンを押す。サーバーは撮影中起動しておく。
4. Viewerを日本語にし、幅・高さ400px、SVG・GIFの非表示をオフにする。小さい図形だけが除外され、7点が表示される想定。実際の件数を確認する。
5. ViewerのDevToolsでデバイスツールバーを開き、Responsive、幅1280・高さ800、デバイスタイプDesktopを選ぶ。ブラウザーのズームは100%。
6. サイズ設定バーの右端のメニューから「スクリーンショットをキャプチャ」（Capture screenshot）を選び、一覧を保存する。コマンドメニューで「スクリーンショット」または「screenshot」を検索してもよい。「Capture full size screenshot」は使用しない。PNGが1280×800であることを確認する。
7. 湖の写真を開き、全体が画面に収まる拡大表示を撮影する。先頭の写真では左矢印が出ないのが正常。右矢印・閉じる操作を含める。
8. 写真をクリックして原寸表示へ切り替え、山肌や水面などの細部が見える位置へドラッグして撮影する。
9. 一覧へ戻り英語に切り替えて一覧を撮影する。拡大・原寸は言語による見た目の違いがないため共通画像を使用する。

## 撮影済みスクリーンショット

ユーザー撮影の画像を確認し、1280×800pxのままJPEGに変換した。品質92、色差の間引きなし。文字・操作部分と風景を確認済み。

| 用途 | ファイル |
| --- | --- |
| 日本語の一覧 | `screenshots/ja/01-grid.jpg` |
| 英語の一覧 | `screenshots/en/01-grid.jpg` |
| 共通の拡大表示 | `screenshots/shared/02-zoom.jpg` |
| 共通の原寸表示 | `screenshots/shared/03-original.jpg` |

ストア登録時は各言語の一覧を1枚目、共通の拡大・原寸を2・3枚目に指定する。拡大・原寸の日英PNGはSHA-256が一致していたため共通化した。

Git管理するスクリーンショットは上記JPEG4枚のみ。元PNG6枚はユーザーの依頼により削除済み。合計容量は約10.56MBから約1.32MBへ削減した。現在のスクリーンショットで進める方針をユーザー確認済み。

撮影後はサーバーをCtrl+Cで停止する。

ブラウザーの枠・DevTools・個人情報を写さず、拡張画面を全面に使用する。実装外のボタンや件数を描き足さない。PNGを変形してサイズを合わせず、撮影時の表示領域を指定する。
